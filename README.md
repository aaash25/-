# VLM 视觉编码器方法迁移

本仓库用于维护 VLM 视觉编码器上的方法迁移、独立核对与版本迭代。

## 范围

计划按 `models/<model>/<method>/` 分别管理四个模型与四种方法，共 16 个组合。

模型：Qwen2-VL-2B、SmolVLM2-2.2B、LLaVA-1.5-7B、LLaVA-OneVision-7B。每个组合将记录实际 checkpoint ID、revision、精度、依赖与推理后端，不能仅凭简称混用权重。

方法：iLLaVA、PiToMe、DToMe、IPCV。研究范围是视觉编码器分支；不把 LLM token 减少带来的收益算作 ViT 加速比。

## 当前状态

当前仅初始化工程说明，组合源码与可公开证据正在按来源、许可证和敏感信息检查后整理。

这不是全部 16 个组合已经通过复现验收的声明。后续每个组合会分别报告作者规则、宿主适配、数值检查、结果来源和计时范围；缺失或未执行的验证明确标记，不以程序能运行代替科学验收。

## 版本与结果

- `main` 表示开发状态，不自动表示已验证版本。
- 可复核版本应使用固定 commit 或 tag。
- 每条质量与计时结果绑定自己的配置和源码版本；后续修复不追溯改写旧结果身份。
- 没有验收通过的 release 时，明确记录“尚无”，不伪造稳定版本。

## 公开范围与第三方来源

公开内容限定为检查后的代码、配置、测试、说明及适合公开的汇总。模型权重、数据集实体、真实基准题干、凭据、会话、个人机器路径和未筛选的原始日志不进入仓库。

第三方代码的许可和署名按具体来源保留；本仓库不为所有上游代码统一重新授权。许可范围尚未明确的代码暂不收录，可先提供来源定位与独立说明。
